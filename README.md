# Moonlit Lake

A cozy 3D fishing game for the web, in early development. M0 is a walkable voxel island — no gameplay yet.

## Tech stack

- [Vite](https://vite.dev/)
- [React 19](https://react.dev/)
- TypeScript
- [React Three Fiber](https://r3f.docs.pmnd.rs/) (Three.js)
- [drei](https://github.com/pmndrs/drei)
- [Zustand](https://zustand.docs.pmnd.rs/)

## Commands

```
npm install
npm run dev      # local dev server
npm run build    # production build
npm test         # run tests
```
